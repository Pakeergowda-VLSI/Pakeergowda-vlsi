## Projects

### 🧠 VedicALU-64X: Pipelined RISC Processor with Vedic Multiplier Hierarchy
*Verilog HDL, Icarus Verilog, Python | Dec 2025 – Jun 2026*
- Architected a 64-bit, 5-stage pipelined RISC processor (IF-ID-EX-MEM-WB) with hazard detection and forwarding logic, plus a custom ISA and Python-based assembler to generate executable machine code.
- Engineered a hierarchical Vedic Mathematics (Urdhva Tiryagbhyam) multiplier, built recursively from 2×2 to 64×64, replacing the standard ALU multiplier to reduce critical-path depth (Vivado STA validation pending).
- Verified full datapath functionality using self-checking testbenches in Icarus Verilog — 545 assertions, 0 failures, across the multiplier hierarchy (416 vectors), ALU (112 checks), and full pipeline (17 register checks covering hazards, forwarding, branches, and jumps).

### 🔌 Parameterized UART Core for VLSI/FPGA Synthesis
*Verilog HDL, Icarus Verilog, Yosys | Feb 2026 – May 2026*
- Designed a fully parameterized UART transmitter/receiver core with synchronous TX/RX FIFOs and a memory-mapped register interface, configurable across baud rate, data/stop bits, and parity for ASIC/FPGA reuse.
- Engineered a 16× oversampling receiver with majority-vote sampling and a 2-FF synchronizer for noise immunity and metastability protection.
- Verified with a self-checking testbench — 100% pass rate across all 7 test cases (reset, TX/RX, loopback, FIFO burst, frame/parity error detection).
- Synthesized for Xilinx Spartan-7 FPGA: ~120 LUTs, ~80 flip-flops, 0 DSP/BRAM usage, Fmax > 100 MHz.
