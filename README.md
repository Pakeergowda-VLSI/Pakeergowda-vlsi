## 🧬 About Me

I'm a final-year **Electronics & Communication Engineering** undergraduate focused on **RTL Design and Design Verification** for ASIC/SoC applications. My work centers on building synthesizable digital hardware — from pipelined processor microarchitecture down to protocol-level IP cores — and proving correctness through rigorous, self-checking verification.

I designed and verified a 64-bit, 5-stage pipelined RISC processor with hazard detection and forwarding, featuring a hierarchical Vedic Mathematics multiplier engineered to reduce critical-path depth — an approach that blends classical Indian mathematical methods with modern processor architecture. Alongside that, I've shipped a fully parameterized, FPGA-synthesized UART core and worked hands-on with embedded systems (STM32, ARM, AVR) across two internships.

## 🚀 Featured Projects

<details>
<summary><b>🧮 VedicALU-64X — Pipelined RISC Processor with Vedic Multiplier Hierarchy</b></summary>
<br/>

A 64-bit, 5-stage pipelined RISC processor (IF-ID-EX-MEM-WB) with hazard detection and forwarding logic, a custom ISA, and a Python-based assembler — featuring a hierarchical Vedic Mathematics (Urdhva Tiryagbhyam) multiplier built recursively from 2×2 to 64×64 to reduce critical-path depth versus a conventional ALU multiplier.

| Aspect | Detail |
|---|---|
| **Stack** | Verilog HDL, Icarus Verilog, Python |
| **Scale** | 5-stage pipeline · custom ISA · recursive 2×2→64×64 multiplier tree |
| **Verification** | 545 assertions, 0 failures — multiplier hierarchy (416 vectors), ALU (112 checks), full pipeline (17 register checks: hazards, forwarding, branches, jumps) |
| **Performance** | Vivado STA validation pending (critical-path reduction target) |
| **Timeline** | Dec 2025 – Jun 2026 |
| **Repository** | *Link your repo here* |

Architected with an emphasis on correctness-first design: every structural block — from the multiplier tree to the full 5-stage datapath — was proven through self-checking testbenches before integration, mirroring an industry-grade RTL-to-verification workflow.

</details>

<summary><b>🔌 Parameterized UART Core for VLSI/FPGA Synthesis</b></summary>
<br/>

A fully parameterized UART transmitter/receiver core with synchronous TX/RX FIFOs and a memory-mapped register interface, configurable across baud rate, data/stop bits, and parity for ASIC/FPGA reuse.

| Aspect | Detail |
|---|---|
| **Stack** | Verilog HDL, Icarus Verilog, Yosys, Xilinx Vivado |
| **Scale** | Parameterized TX/RX core with FIFO buffering, memory-mapped registers |
| **Verification** | 100% pass rate across all 7 test cases (reset, TX/RX, loopback, FIFO burst, frame/parity error detection) |
| **Robustness** | 16× oversampling with majority-vote sampling + 2-FF synchronizer for metastability protection |
| **Performance** | ~120 LUTs, ~80 flip-flops, 0 DSP/BRAM usage, Fmax > 100 MHz on Xilinx Spartan-7 |

Built for reuse — the register interface and configurability make this core drop-in ready across different ASIC/FPGA targets without RTL changes.
